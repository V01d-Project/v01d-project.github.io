## 二、老站点（`gaokao-training/`）现在有什么

站点引擎：纯静态，一份 `assets/app.js` + 一份 `assets/app.css`；一章一页 `<科目>/<书号>-<章号>/index.html`（**逐字节相同**，内容全在数据文件里）；目录在 `data/index.js`。
数据文件**三种形态**（`tmp/check-en.cjs` 是校验脚本）：

| 形态 | 字段 | 渲染成 |
|---|---|---|
| 讲解教程 | `sections[]`，段件可用 `str` / `{li}` / `{tip}` / `{code}` / `{en,zh}`；`sections[].ex[]` = 例题 `{q,a[],tip}` | 可交互教程 + 「点我看思路」例题 |
| 背诵卡 | `items[]` = `{en,zh,note}`，`hideDefault:'en'或'zh'` | 打开即遮住该练的一档 |
| 题卡 | `questions[]` = `{k,q,a}` | 生物/语文那套 ①②③ |

## 三、三块的规划（作文 / 完形词块 / 语法填空）

按清雪自己定的顺序排（背了就有分、见效最快）：

### 块 1 · 作文（40 分）—— 优先级最高
分两条腿：**应用文 15** + **读后续写 25**。理由：写作 40 分是三块里权重最大的，而且**格式分和结构分不靠英语水平就能拿**，对基础差的学生性价比最高。

**应用文现状**：`3-1` 已讲透评分 / 三段结构 / 称呼敬语落款 / 中译英 / 八个毛病；`3-2~3-7` 已备好六类信件的**词块与句型共 95 条**。
→ **还缺什么（这是真缺口，不是重复）**：
1. **范文拆解**——站上一条都没有。学生手里有词块，却不知道一篇完整答案长什么样、每一句在完成什么任务。
2. **审题训练**——把题目要点转成句子骨架的那一步，目前只在 `3-1` 提了一句。
3. **真题改编**——站上素材是自编的，没有真题情境。

**读后续写现状**：`4-1` 四步法 + `4-2` 高分句式 60 条。
→ 缺口：真题原文 + 范文 + 「怎么把 60 条句式用出去」的示范。

**块 1 的批次安排**
| 批次 | 内容 | 形式 | 量 |
|---|---|---|---|
| **第 1 批（已交付 9/18）** | **范文拆解**：3 篇范文（2 篇真题情境 + 1 篇通知自拟）+ 可迁移词块 | 新章 `3-8`（教程 + 例题） | 5 节 / 5 例题 ✅ |
| **第 2 批（已交付 9/18）** | 审题 · 要点转句子（给题目 → 列骨架 → 检查要点） | 新章 `3-9`（教程） | 5 节 / 6 例题 ✅ |
| **第 3 批（已交付 9/18）** | 读后续写真题原文 + 范文拆解 | 新章 `4-3` | 4 节 / 4 例题 ✅（2021/2022/2024 真题情境 + 1 自拟；范文为自写） |

### 块 2 · 完形词块（15 分）—— 优先级第二
**现状**：`2-1` 四类线索教程 + `2-2` 词块辨析 68 条（看 / 说 / 听 / 笑哭 / 找查 / 增减 …）。

## 四、交付形式（往后统一按这个来）

1. **数据写进站点，不另起 md**。本站 `sections` + `ex` 形态天然就是「教程 + 边读边练」，比 md 好：能标 ①②③、能复制结果发回来。
2. 新增一章 = 三步：
   - 写 `data/english/<书>-<章>.js`（`window.QUIZ_DATA`，带 `bookId/bookName/chapterId/chapterName`）
   - 建页面 `english/<书>-<章>/index.html`（**照抄任意已有章节页，一字不改**）
   - 在 `data/index.js` 对应 book 的 `chapters` 里加一行 `live: true`
3. 写完必须跑 `node tmp/check-en.cjs` 自检（例题有没有题面、块类型合法、`hideDefault` 有没有给），异常必须为 0。
4. 英语各 book 一律 `noReview: true`（不生成「整本检测」入口），沿用现状。
5. 刻意不做的事：不新增科目、不动 `assets/`、不动已有章节内容（除下面第 5 节的改错）、不 git push（等清雪要上线时再说）。
