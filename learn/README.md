# 题库 · Quiz

一个纯静态的自测题库页面。一章一页，勾「会 / 模糊 / 不会」，点一下把结果复制到剪贴板。

**零依赖、零后端、零构建** —— 扔到任何静态托管上就能跑。

---

## 用法

1. 打开首页，选科目 → 选章节。
2. 每题三个按钮：**① 会 / ② 模糊 / ③ 不会**。点一下标上，再点一下取消。
3. 想自己对答案，点每题右边的 **「答案」**。
4. 标完点底部 **「复制结果」**，得到这样一段：

```
【生物 必修一 第1章 走近细胞】共 28 题 · ①会 20 / ②模糊 6 / ③不会 2
② 模糊：细胞学说的建立者 / 常见原核生物
③ 不会：细胞学说内容 / 生命活动离不开细胞
```

标记存在浏览器 `localStorage` 里，**关掉再开还在**，每章各存各的。

> 设计意图：导出**只列②③**，①只报个数。一章 30 题压成两三行，发给老师/家长/自己的复习本都省事。

## 目录结构

```
.
├── index.html                 首页（科目目录）
├── assets/
│   ├── app.css                全站唯一一份样式
│   └── app.js                 全站唯一一份逻辑
├── data/
│   ├── index.js               全站目录（加科目/章节改这里）
│   └── bio/
│       ├── 1-1.js             必修一 第1章 的题目
│       └── ...
└── bio/
    ├── 1-1/index.html         必修一 第1章 的页面
    └── ...
```

**路径约定**：章节页必须是 `<科目>/<书号>-<章号>/` 这样的**两层目录**。
`app.js` 靠这个路径反推该加载哪个数据文件，所以页面 HTML 是**逐字节相同**的——
换一章，只换数据文件。

书号约定：`1` `2` = 必修一 / 必修二，`3` `4` `5` = 选择性必修一 / 二 / 三。

## 加一章

1. 写数据文件 `data/<科目>/<书号>-<章号>.js`：

```js
window.QUIZ_DATA = {
  subject: '生物', subjectId: 'bio',
  bookId: 1, bookName: '必修一 分子与细胞',
  chapterId: 7, chapterName: '第7章 某某',
  questions: [
    { k: '知识点标签', q: '题干？', a: '答案。' }
  ]
};
```

2. 复制任意章节页到一个新目录，比如 `bio/1-7/index.html`（内容不用改一个字）。

3. 在 `data/index.js` 里加上这一章，并把 `live: true` 打开（`live` 为假显示为「待录入」）。

## 部署

纯静态，随便放：

- **GitHub Pages**：仓库 Settings → Pages → Source 选分支根目录。仓库里已经有 `.nojekyll`。
  - 仓库名形如 `<用户名>.github.io` → 网站就在根路径，访问 `https://<用户名>.github.io/`
  - 其他仓库名 → 网站挂在子路径，访问 `https://<用户名>.github.io/<仓库名>/`
  - 两种都能跑，因为页面用的是相对路径。
- **Cloudflare Pages / Netlify / Vercel**：直接指向仓库即可，无需构建命令。
- **自己的服务器**：把整个文件夹丢进 Nginx/Apache 的 web 根目录。
